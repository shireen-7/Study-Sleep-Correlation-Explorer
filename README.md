📊 Study-Sleep Correlation Explorer
📌 Project Overview

The Study-Sleep Correlation Explorer is a data analytics and visualization project that examines how students' study habits and sleep duration influence their academic performance.

This project uses simple datasets and powerful visualization techniques to uncover patterns and help students understand the importance of maintaining a balanced routine.

🎯 Objectives

Analyze the relationship between study hours, sleep duration, and grades

Identify optimal ranges for better academic performance

Apply Exploratory Data Analysis (EDA) techniques

Create meaningful visualizations to interpret patterns

Provide data-driven insights for students and educators
